# Aktineu Website

React landing page for **Aktineu LLP**, built from the wireframe layout with content and colors from [aktineu.com](https://aktineu.com/).

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build for production

```bash
npm run build
npm run preview
```

## Structure

- **Navbar** — Brand, navigation links, Register/Login
- **Hero** — Headline, stats, testimonials carousel
- **All you should know** — Why choose Aktineu + comparison (VS)
- **Process** — Investment Process, Portfolio Framework (TRI), Investor Lifecycle
- **Products** — MF | PMS | AIFS | FD | SIF | Gift City
- **Footer** — FAQ, Schedule a call, WhatsApp button

## Tech stack

- React 19 + Vite
- Plain CSS (no UI framework)
- Fonts: Manrope, Poppins, Inter (matching aktineu.com)
